## 🚀 Project Overview

The **Student Analytics & Machine Learning System** is a Python-based application designed to manage student records and perform data analysis using important concepts from:

- Python
- Object-Oriented Programming
- Statistics
- Probability
- Conditional Probability
- Bayes Analysis
- Normal Distribution
- Correlation
- Linear Regression
- Hypothesis Testing
- Data Visualization
- Machine Learning

The system allows users to manage student records and analyze both:

- 👨‍🎓 Individual Student Performance
- 🏫 Complete Class Performance

Student data is automatically stored in a **CSV file**, which works as a local database.

This project is designed as a practical application of the mathematical and statistical concepts commonly used in **Data Science, Machine Learning, and Artificial Intelligence**.

# ✨ Features

## 👨‍🎓 Student Management

The system provides complete student management functionality:

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Individual Student
- ✏️ Update Student Information
- 🗑️ Delete Student
- 💾 Automatically Save Data

The system follows CRUD operations:

| Operation | Description |
|---|---|
| Create | Add a new student |
| Read | View or search student data |
| Update | Update student information |
| Delete | Remove a student |

- Student Rank

- Bayes Analysis
